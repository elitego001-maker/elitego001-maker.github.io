Three Tools I Use Every Day (And Why)

The small set of tools that actually earned a permanent place in my workflow.

  • 3.What They Have in Common

I install a lot of tools. Most get uninstalled within a week — either they solved a problem I didn't really have, or they solved a real problem in a way that added more friction than it removed. These three are the exceptions. I've used all of them daily for over a year.

Chapter 1 — Why Most Tools Don't Survive a Month

The pattern I keep noticing: a tool sticks when it removes a step, not when it adds a dashboard. Anything that asks me to change my habits to fit its workflow gets abandoned the first busy week. Anything that quietly slots into what I already do survives.

Chapter 2 — The Three That Did
  • A terminal-based password manager — no browser extension, no cloud dashboard, just a CLI command and a keyboard shortcut. It's faster than typing the password myself, which is the only bar a password manager actually needs to clear.
  • A single scratch notes file, synced, no app — one plain-text file instead of a "notes app." Zero friction to open, zero decisions about where something goes, searchable with tools I already know.
  • A window manager with keyboard-only navigation — removed the single most repeated motion in my day: reaching for the mouse to switch windows. Small saving per switch, huge saving across a year.
None of these are exciting. That's kind of the point — the tools that last are the ones you stop noticing.
Chapter 3 — What They Have in Common

Every one of these replaced a small, repeated, physical action — typing, clicking, searching — with something faster, and none of them asked me to adopt a new mental model to get there. That's the filter I use now before installing anything new: does this remove a step, or just move the step somewhere else?
